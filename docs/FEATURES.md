# 功能说明

## 视频列表

递归扫描所选目录，根据路径、文件大小和修改时间识别视频。支持 MP4、MOV、MKV、AVI、TS、M4V、WebM、MTS；实际解码能力取决于 FFmpeg。

抽帧间隔可设为 0.5–3600 秒，默认 5 秒。可开启 `mpdecimate` 删除近似静态帧。抽帧时暂存当前视频的 JPEG 帧，拼图完成后清理临时帧。

暂停会终止当前 FFmpeg 进程；继续会重新处理当前未完成视频，并跳过已完成视频。改变抽帧参数不会自动重做已完成项。

## 宫格列表

每张图片为 1280 × 720 的 4 × 4 宫格，格子从左到右、从上到下编号，包含视频内时间。剩余不足 16 帧时留黑。提供全部、收藏夹、AI 命中三个筛选入口。

点击大图可查看时间和分析描述，并在 Finder 定位原视频。目前没有内嵌播放器或点击时间跳转播放。

## 分析中心

填写 Base URL、API Key 和支持图像的模型名，调用 `POST {Base URL}/chat/completions`。Base URL 应包含服务要求的版本路径，如 `/v1`。

用户输入至少 10 字的分析意图。每次请求发送一张宫格，以 Base64 图像传输，最多 4 路并发。解析 JSON 中的命中状态、0–100 置信度、格子编号和说明；置信度为模型给出的判断，不是经过校准的统计概率。

- 开始 / 继续：处理未完成项，并重试失败项。
- 暂停：停止派发新请求，等待已经发出的请求结束。
- 重新分析：清空本轮结果并重新请求全部图片。
- 更改意图：需要重新分析，避免不同意图结果混用。

暂停与恢复不包含计费回滚。接口失败时不会自动无限重试，需点击继续分析。

## 保存与恢复

当前目录索引、收藏和分析结果保存在本机。切换目录时保存旧目录快照，重新扫描旧目录可恢复记录。移动或修改视频会改变其标识，可能需要重新处理。

## 当前限制

- 仅针对 macOS；选择文件夹和 Finder 定位依赖系统工具。
- 只提供浏览器界面和启动脚本，没有签名安装包。
- 采样或静态过滤可能遗漏短暂事件。
- 不包含人员身份识别、跨镜头追踪或犯罪判定功能。
- 尚无片段导出、缓存管理、大规模分页、费用预估和自动退避重试。
- 真实 API 兼容性、长时间批处理及识别准确率尚待验证。
- 参考截图中的每路 4 张批次未实现，目前每路 1 张。
