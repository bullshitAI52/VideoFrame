# 功能说明

## 产品定位：智能查监控

核心任务是帮助用户从大量监控录像中查找线索。输入要找的目标，例如“寻找携带黑色提包经过走廊的人”，由 AI 筛选候选画面，用户结合文件名、格子编号及视频内时间回看核实。

当前已实现采样画面的批量筛选、命中说明、时间查看与收藏。抽帧和宫格服务于这一检索流程。时间戳为视频内相对时间，不是摄像头真实日期时间；尚未实现录像时钟解析或事件连续追踪。


## 视频列表

递归扫描所选目录，根据路径、文件大小和修改时间识别视频。支持 MP4、MOV、MKV、AVI、TS、M4V、WebM、MTS；实际解码能力取决于 FFmpeg。

抽帧间隔可设为 0.5–3600 秒，默认 5 秒。可开启 `mpdecimate` 删除近似静态帧。若视频短于采样间隔而没有输出画面，会补取首帧。抽帧时暂存当前最多 1 小时的 JPEG 帧，该段拼图完成并保存进度后清理临时帧。

暂停会终止当前 FFmpeg 进程。内部每 1 小时保存一次进度，继续时跳过已完成段，只重做未完成段；原视频不切割。每张宫格属于一个分段，不跨小时拼图，时间戳保留相对于原始全天录像的时间。已开始的视频沿用首次处理参数；旧版已完成结果无需重做。

## 宫格列表

每张图片为 1280 × 720 的 4 × 4 宫格，格子从左到右、从上到下编号，包含视频内时间。剩余不足 16 帧时留黑。提供全部、收藏夹、AI 命中三个筛选入口。

点击缩略图中的有效格子可直接打开原视频，从该帧前 5 秒开始播放（不足 5 秒则从开头开始）。也可在宫格大图中选择格子，AI 命中格子以紫色标记。

播放器显示文件名、选中帧时间和回看起点，支持暂停、拖动进度及 0.5×、1×、1.5×、2×、4× 倍速。关闭弹窗会停止播放并释放视频连接。原视频通过本地分段读取播放，不会上传或一次性加载整个文件到服务端内存。

播放兼容性取决于浏览器支持的容器和编码，不是所有能抽帧的视频都能直接播放。原文件被移动或编码不支持时会显示提示，可在 Finder 中打开原视频并按时间定位。目前不自动转码。

## 分析中心

填写 Base URL、API Key 和支持图像的模型名，调用 `POST {Base URL}/chat/completions`。Base URL 应包含服务要求的版本路径，如 `/v1`。

用户输入至少 10 字的分析意图。每次请求发送一张宫格，以 Base64 图像传输，最多 4 路并发。解析 JSON 中的命中状态、0–100 置信度、格子编号和说明；置信度为模型给出的判断，不是经过校准的统计概率。

- 开始 / 继续：处理未完成项，并重试失败项。
- 暂停：停止派发新请求，等待已经发出的请求结束。
- 重新分析：清空本轮结果并重新请求全部图片。
- 更改意图：需要重新分析，避免不同意图结果混用。

暂停与恢复不包含计费回滚。接口失败时不会自动无限重试，需点击继续分析。

## 保存与恢复

当前目录索引、收藏和分析结果保存在本机。切换目录时保存旧目录快照，重新扫描旧目录可恢复记录。移动或修改视频会改变其标识，可能需要重新处理。

## 当前限制

- 仅针对 macOS；选择文件夹和 Finder 定位依赖系统工具。
- 只提供浏览器界面和启动脚本，没有签名安装包。
- 采样或静态过滤可能遗漏短暂事件。
- 不包含人员身份识别、跨镜头追踪或犯罪判定功能。
- 尚无片段导出、缓存管理、大规模分页、费用预估和自动退避重试。
- 真实 API 兼容性、长时间批处理及识别准确率尚待验证。
- 参考截图中的每路 4 张批次未实现，目前每路 1 张。
