# 使用说明

## 产品定位：智能查监控

核心任务是帮助用户从大量监控录像中查找线索。输入要找的目标，例如“寻找携带黑色提包经过走廊的人”，由 AI 筛选候选画面，用户结合文件名、格子编号及视频内时间回看核实。

当前已实现采样画面的批量筛选、命中说明、时间查看与收藏。抽帧和宫格服务于这一检索流程。时间戳为视频内相对时间，不是摄像头真实日期时间；尚未实现录像时钟解析、事件连续追踪或直接跳转播放。


按参考截图实现的本地程序，包含深色导航、视频列表、16 宫格列表、收藏筛选和 AI 分析中心。不是原软件源码，也不承诺逐像素一致。

## 启动

1. 需要 Python 3.10+、FFmpeg 和 ffprobe。请在终端使用 `python3 --version`、`ffmpeg -version` 和 `ffprobe -version` 检查。
2. 双击 `启动.command`。首次启动会在程序目录创建 `.venv`，从 Python 包仓库安装 Pillow 和 requests。
3. 浏览器自动打开 http://127.0.0.1:8765 。保持终端窗口打开；停止服务按 Ctrl+C。

也可在此目录运行 `python3 -m pip install -r requirements.txt`，随后执行 `python3 server.py`。如端口被占用，可用 `VIDEOFRAME_PORT=8767 python3 server.py` 并访问对应端口。

## 使用流程

- 点击“切换目录”，或在视频列表手工填写本地目录并扫描。递归发现 MP4、MOV、MKV、AVI、TS、M4V、WebM、MTS 视频。
- 设置抽帧间隔，选择是否过滤近似静态帧，然后开始抽帧。每 16 帧拼成一张图，不足 16 帧的区域留黑。原视频不会修改。
- 在宫格列表点击图片查看大图、格子编号和视频时间。可收藏，或在 Finder 定位原视频。
- 在分析中心填写兼容 Chat Completions 的接口 Base URL（通常以 `/v1` 结尾）、API Key、支持图像输入的模型名称。
- 输入至少 10 字的分析意图，然后开始分析。最多 4 路并发，每次请求 1 张宫格；与参考截图“每路 4 张”的调度方式不同。
- 继续分析重试失败项和未完成项。重新分析清空本轮 AI 结果并重新请求全部宫格。更换意图需要重新分析。

## 数据与边界

数据保存在 `~/Library/Application Support/VideoFrame`。切换目录保存各目录的索引；回到旧目录扫描可恢复收藏和分析记录。密钥保存在 `config.json`，文件仅当前用户可读写，但没有进行加密。密钥不会返回给前端或写入视频目录。

视频处理在本地进行；只有点击 AI 分析后才会把宫格图发送至配置的服务，接口可能收费。应用仅监听 127.0.0.1，不作为公网服务部署。

暂停抽帧后，继续时会重新处理当前未完成视频，已完成视频跳过。抽帧参数修改不会自动重做已完成视频。暂停 AI 会等待正在处理的最多 4 个请求结束。逐帧精确定位、内嵌视频播放、视频片段导出和安装包暂未实现。

抽帧会暂存当前视频的 JPEG 帧，完成后删除临时帧，保留宫格。长视频请预留磁盘空间。采样与静态过滤可能漏掉短暂事件；AI 命中和置信度只是模型判断，需回看原视频核实。
